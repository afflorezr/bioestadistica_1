\textbf{\large Descripción del curso}

El curso introduce los fundamentos de estadística descriptiva, probabilidad e inferencia estadística. Se promueve el análisis de datos reales mediante el uso del software R, así como la interpretación crítica de resultados en contextos económicos.

\vspace{1em}

\textbf{\large Objetivo de formación}

Desarrollar el pensamiento estadístico en la formación profesional del estudiante, proporcionándole una comprensión sólida del lenguaje estadístico que le permita representar, analizar e interpretar fenómenos económicos. Se busca fortalecer su capacidad para modelar problemas reales, promover el uso adecuado de herramientas computacionales como R y fomentar una lectura crítica de la información estadística en el contexto de la investigación.

\vspace{1em}

\textbf{\large Objetivos pedagógicos}

El estudiante que curse la asignatura y cumpla con las exigencias académicas podrá:
\begin{itemize}
    \item Utilizar medios estadísticos para la presentación y resumen de datos.
    \item Describir apropiadamente bases de datos de acuerdo con la naturaleza de sus variables.
    \item Identificar la estructura general de la inferencia estadística como base para la comprensión del lenguaje estadístico.
    \item Adquirir y aplicar conceptos de probabilidad como herramientas descriptivas y de apoyo conceptual.
    \item Realizar estimaciones por intervalo a partir de muestras simples.
    \item Traducir conjeturas científicas a lenguaje estadístico y valorar su plausibilidad.
    \item Iniciar el modelamiento estadístico y la interpretación de resultados en el contexto de la investigación y experimentación.
    \item Apoyarse en el uso de software estadístico para el análisis de datos.
\end{itemize}

\vspace{1em}

\textbf{\large Metodología}

El curso estará compuesto por clases magistrales y sesiones prácticas apoyadas en software estadístico (R), en las que se desarrollarán ejemplos aplicados. Se propondrán talleres para que los estudiantes apliquen los conceptos aprendidos, automaticen procedimientos y analicen e interpreten resultados. Adicionalmente, se promoverá la lectura previa de los temas y la discusión crítica de aplicaciones estadísticas en investigación.

\vspace{1em}

\textbf{\large Contenido}

\begin{enumerate}
    \item{Introducción}
    \begin{itemize}
        \item Pasos y tipos de investigación
        \item Definiciones iniciales en estadística
        \item Clasificación de variables
        \item Escalas de medición
    \end{itemize}

    \item{Estadística descriptiva de una variable}
    \begin{itemize}
        \item Presentación tabular y gráfica
        \item Medidas de tendencia central, dispersión y forma
        \item Datos atípicos
        \item Tasas, razones y proporciones
    \end{itemize}

    \item{Estadística descriptiva de dos variables}
    \begin{itemize}
        \item Tablas y gráficos bivariados
        \item Medidas de correlación
    \end{itemize}

    \item{Probabilidad}
    \begin{itemize}
        \item Experimento aleatorio, espacio muestral y eventos
        \item Definición de probabilidad y propiedades
        \item Probabilidad condicional e independencia
        \item Teorema de Bayes
        \item Reglas de conteo
    \end{itemize}

    \item{Variables aleatorias}
    \begin{itemize}
        \item Definición y tipos
        \item Funciones de probabilidad y densidad
        \item Valor esperado y varianza
        \item Percentiles
    \end{itemize}

    \item{Distribuciones de probabilidad}
    \begin{itemize}
        \item Distribución Bernoulli y binomial
        \item Distribución de Poisson
        \item Distribución uniforme
        \item Distribución exponencial
        \item Distribución normal
    \end{itemize}

    \item{Inferencia estadística}
    \begin{itemize}
        \item Tipos de muestreo
        \item Distribuciones muestrales
        \item Teorema Central del Límite
    \end{itemize}
    
    \item{Estimación de parámetros}
    \begin{itemize}
        \item Estimadores e intervalos de confianza
        \item Estimación de la media y la proporción
        \item Tamaño de muestra
    \end{itemize}

    \item{Pruebas de hipótesis}
    \begin{itemize}
        \item Conceptos fundamentales
        \item Errores tipo I y II
        \item Valor-p
        \item Pruebas para la media, proporción y varianza
        \item Comparación de medias y proporciones
        \item Razón de varianzas
    \end{itemize}

    \item{Regresión lineal simple}
    \begin{itemize}
        \item Modelo de regresión
        \item Método de mínimos cuadrados
        \item Estimación de parámetros
        \item Evaluación del modelo
    \end{itemize}

    \item{Regresión lineal múltiple}
    \begin{itemize}
        \item Modelo de regresión múltiple
        \item Inferencia y diagnóstico del modelo
        \item Aplicaciones y ejemplos
    \end{itemize}

    \item{Análisis de Varianza y Diseño de Experimentos}
    \begin{itemize}
        \item Modelo de Análisis de Varianza (ANOVA) de un factor
        \item Verificación de supuestos y comparación de medias
        \item Diseño de Bloques Completos Aleatorizados, Cuadrado Latino y Cuadrado Greco-Latino
        \item Diseños Factoriales
    \end{itemize}

    \item{Análisis de concordancia}
    \begin{itemize}
        \item Coeficiente Kappa
        \item Kappa ponderado
        \item Correlación intraclase
    \end{itemize}

\end{enumerate}
